# Ripple

Ripple is a Claude Code mod that maps what a code change reaches. Run `/ripple` and a background agent traces what depends on the code you changed, and the map is drawn in a pane inside Claude Code: what changed, what uses it, and which of those the change breaks.

```
/plugin install ripple --marketplace nsodhi-cmu/claude-code-ripple
```

The repository's [README](https://github.com/nsodhi-cmu/claude-code-ripple#readme) says how to use it and what it does with the access a mod has.
